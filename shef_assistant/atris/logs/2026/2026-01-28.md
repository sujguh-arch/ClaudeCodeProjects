### Vision: Smart Auto-Ordering System

**Goal**: Hands-off meal ordering with availability checks and smart reminders.

**Core Flow:**
1. **Daily dish list** → Set dishes I want every day
2. **Availability check** → Verify dishes are in stock before ordering
3. **Auto-prefill** → Add available dishes to cart (already working)
4. **Reminder system** → Check if I'm out of food
5. **Auto-trigger** → Based on reminder, kick off automation

**Principles:**
- Pareto (80/20): High-value features first, skip edge cases initially
- Parkinson's: Tight scope, ship fast, iterate
- Step-by-step: Max accuracy over speed

**Current Gaps:**
- No availability checking
- No reminder/scheduling system
- Manual trigger only (need auto-trigger based on food status)
