# Strategy Memo Template

## Artifact Structure
```
artifact/
├── memo.md                # The full strategy document (2000-3000 words)
├── executive-summary.md   # 1-page version for email attachment (under 500 words)
├── appendix/
│   ├── market-data.md     # Supporting data and analysis
│   └── technical-spec.md  # Technical feasibility assessment
└── prototype/             # Optional: working code that proves a key claim
```

## memo.md Template

```markdown
# [Title]: [Specific Recommendation for Company]

## Executive Summary
[3-4 sentences: the problem, the recommendation, the expected impact]

## The Problem
[What the company is struggling with — must reference specific evidence from intel.md]
[Include competitive dynamics — who's solving this better and how]

## Why This Matters Now
[Why the timing is right — reference recent news, market shifts, or company moves]

## The Approach
### Option A: [Recommended]
[Detailed description with technical specifics]
[Why this works — reference earned secrets and real experience]

### Option B: [Alternative considered]
[Why this is less optimal — honest trade-off analysis]

## Implementation Roadmap
### Phase 1 (Weeks 1-4): [Name]
- [Specific deliverable]
- [Metric to validate]

### Phase 2 (Weeks 5-8): [Name]
- [Specific deliverable]
- [Metric to validate]

### Phase 3 (Weeks 9-12): [Name]
- [Specific deliverable]
- [Metric to validate]

## Why I'm Confident This Works
[Reference to solving similar problems at Duetto/C1/JPMC — specific metrics from fact-set]
[The earned secret that makes this recommendation non-obvious]

## Risks & Mitigations
| Risk | Likelihood | Mitigation |
|---|---|---|
| [risk] | [H/M/L] | [specific mitigation] |

## About the Author
[2-sentence bio connecting to this specific problem domain]
```

## Depth Requirements Checklist
- [ ] Problem references specific evidence from company intel (not generic)
- [ ] Recommendation is actionable (someone could start executing next week)
- [ ] Technical specifics demonstrate builder credibility (not consultant-speak)
- [ ] At least 1 earned secret woven into the "Why I'm Confident" section
- [ ] Trade-offs are honest (not just cheerleading the recommendation)
- [ ] Roadmap has specific metrics, not just milestones
- [ ] Executive summary stands alone as a compelling 1-pager
