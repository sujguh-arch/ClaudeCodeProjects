# Advanced Pipeline Evaluation Criteria (Tier 2)

**Purpose:** 20 additional evals per stage that test deeper quality signals — nuance, authenticity, strategic thinking, and "would this actually work" pragmatism.

Use these AFTER passing Tier 1 (EVAL-CRITERIA.md). A pipeline run is exceptional when both tiers pass.
